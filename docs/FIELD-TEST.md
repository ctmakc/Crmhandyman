## 3. Три вопроса, ради которых делалась волна

### 3.1. Скорость реакции: тапов от «пришло уведомление» до «звоню»

| Состояние | Действий | Разбор |
|---|---|---|
| Канал не настроен (состояние нового воркспейса) | сигнала нет | Три лида пришли через настоящую дверь приёма, доставка выключена по умолчанию, строки в журнале нет. Владелец узнаёт о лиде, когда сам откроет CRM |
| Telegram настроен, звонок из самого сообщения | 4–5 | Номер печатается как есть — `613-555-0142`. Telegram делает тапаемыми номера в международном формате, местный остаётся текстом: долгий тап → «копировать» → набор → вставить → вызов |
| Telegram настроен, ссылка из сообщения, сессия жива | **3** | Тап по ссылке → карточка лида → `CALL`. Ровно то, ради чего волна делалась |
| Telegram настроен, ссылка из сообщения, сессия истекла за ночь | **8–9** | Ссылка → `/login?tenant=demo&callbackUrl=%2Fleads%2F<id>` → почта → пароль → Sign in → **приземление на Dispatch**, адрес лида потерян. На телефоне дальше: прокрутить дашборд до низа → тап по строке лида → `CALL`. Причина в `src/app/(auth)/login/page.tsx:34,40`: `signIn(..., { redirect: false })` и безусловный `router.push("/")`, `callbackUrl` не читается |

Утренний сценарий — телефон, ночь без сессии — попадает в последнюю строку.

### 3.2. Отчёт по каналам: «куда лить следующие 400 долларов»

**Отвечает** при двух выполненных условиях. Август на живых данных читается с экрана без
вычислений: Facebook — 3 лида по $137.50, одна работа, $2,214.80 собрано, 5.37× на рекламу;
Google — $168.00 и ноль лидов. Решение очевидно.

Условия, без которых ответ становится ложным:

1. **Работа должна быть заведена из лида.** Работа, созданная с экрана Jobs (заказ по
   телефону, повторный клиент, заявка с улицы), попадает в колонку `No lead on file`, и её
   деньги в канал уже не вернутся. На полном годе демо-базы так лежит **вся** выручка:
   $4,306.40 в `No lead on file`, ноль у каждого канала, итог `AFTER ADS −$934.60`. Экран
   при этом говорит правду о своих данных; способа связать работу с лидом задним числом
   в продукте нет.
2. **Расходы работы должны быть заведены.** При `JOB COSTS $0.00` маржа равна выручке, и
   кратность на рекламу завышена ровно на себестоимость.

**Требует интерпретации** в двух местах. Экран открывается на «Full year», решение по
бюджету принимается по месяцу — переключение владелец должен сделать сам. И в текущем
месяце `COLLECTED` структурно отстаёт от `AD SPEND`: лиды девятиминутной давности денег
принести ещё не успели, поэтому свежий месяц всегда показывает канал в минусе. Оговорка
об этом есть — абзацем мелкого текста под шапкой; крупные числа говорят обратное.

Полезная деталь, которую отчёт делает хорошо: `2 NEVER ANSWERED` в шапке и
`FIRST REPLY 15 MIN` в колонке. Это единственные числа, которые честны с первого дня месяца.

### 3.3. Поле без связи: честность состояния

**Говорит правду там, куда смотрели:**

- возраст доски штампом — `BOARD AS OF 20:54 · NO CONNECTION SINCE`;
- полоса `NO SIGNAL — WORK IS BEING HELD · 1 waiting` с названием каждого удержанного тапа;
- метка на самой карточке `START QUEUED · WAITING JUST NOW`;
- отправка сама по возврату сети, без действий человека.

**Произносит неправду в одном шаге в сторону.** Любая страница вне кэшированной оболочки
(карточка работы, клиенты, работы) отдаёт офлайн-карточку с текстом «This phone has not
opened the board while it had a network, so there is no copy of today's stops to show».
Телефон доску открывал, копия есть, она в одной кнопке «назад». Техник в подвале читает,
что данных нет, и делает вывод, что потерял смену.

**Молчит о границе.** Фото и приём оплаты живут только на карточке работы, то есть офлайн
недоступны. Продукт об этом не сообщает ни до, ни в момент попытки.

## 4. Пять вещей, которые надо починить до передачи клиенту

1. **Вход теряет адрес, на который вёл алерт.** `src/app/(auth)/login/page.tsx:34,40` —
   заменить `router.push("/")` на переход по `callbackUrl` из адресной строки. Ломается
   ровно тот путь, ради которого строилась вся волна скорости: утро, телефон, ночь без
   сессии. Цена правки — одна строка, цена дефекта — шесть лишних действий на каждом
   лиде.
2. **Телефон в уведомлении печатать в международном формате.** `composeMessage` в
   `src/lib/notify.ts` кладёт номер как есть; Telegram делает тапаемым `+1 613 555 0231`
   и оставляет текстом `613-555-0231`. Один префикс превращает четыре действия в одно.
3. **Утренний лист развернуть к сегодняшнему дню.** Свежий неотвеченный лид должен стоять
   выше вчерашних (или дать листу второй порядок «сначала новые» переключателем), а
   `Leads` вынести в нижнюю панель телефона. Сейчас лид возрастом 129 дней занимает верх
   листа вечно, а на телефоне лист лидов достижим только через прокрутку дашборда.
4. **Офлайн-карточка должна говорить правду.** Различать «эта страница требует сети,
   доска сохранена — вернуться к сегодняшнему листу» и «этот телефон доску ни разу не
   открывал». Там же назвать вслух, что фото и приём оплаты ждут сети.
5. **Технику на форме оплаты показать сумму к оплате.** Одна цифра — остаток по счёту этой
   работы, без книги, без маржи, без истории. Иначе человек у двери набирает офис, и
   ролевой фильтр из Б5 GO-LIVE начинает стоить денег на каждом визите.

## 6. Что сработало без единого замечания

- Приём лида с настоящей нагрузкой квиза: `201`, лид в нужном воркспейсе, весь опросник
  в блоке `CALL LOG` человеческими подписями.
- Карточка лида: телефон крупнее заголовка, `tel:`, живой секундомер до ответа и
  застывшее `ANSWERED IN 14M` после.
- Конвертация лид → работа: `201`, связь `FROM LEAD … · FACEBOOK` на карточке, дата
  `Aug 24, 2026` совпадает с введённой (Б1 и Б4 из GO-LIVE закрыты, проверено вживую).
- Деньги: `$412.50`, `$2,214.80`, `$1,954.30` — en-CA, до цента, одинаково на всех экранах
  и в журнале.
- Роли: техник видит форму приёма оплаты и не видит ни одной суммы книги; на карточке
  работы у него три вкладки без экономики; `Invoices` из нижней панели пропал.
