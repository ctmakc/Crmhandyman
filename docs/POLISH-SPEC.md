# POLISH-SPEC — как полировать экран

Волна полишинга, 13.08.2026. Фундамент (токены, примитивы, globals.css, tailwind.config)
приведён в порядок; дальше каждый агент правит свой экран. Функциональность не трогаем.

Закон — `DESIGN.md`. Здесь только то, чего в нём нет: чем собирать, что уже сломано на
твоём экране и как проверить себя перед сдачей.

## 1. Чем собирать

Всё из `@/components/ui/primitives`. Верстать заново нельзя: разнобой соседних экранов
виден сильнее, чем любая отдельная красота.

| Примитив | Заменяет | Заметка |
|---|---|---|
| `PageHead` | свой заголовок экрана | сам ставит 44/34px, `measure` на подзаголовок, кнопку на телефоне — под заголовок |
| `BackLink` | свои «← ALL JOBS» | 6 экранов писали свои, в четырёх кеглях |
| `LaneHead` | свою шапку секции | `right` переносится на вторую строку сам, заголовок не ломается |
| `Row` + `Lane` | свою строку списка | спина + линейка + воздух, без рамки |
| `Ticket` | свою «карточку» | только документ или шапка записи |
| `Button` / `buttonClass(v)` | свои `const act = "..."` | ранги `primary` / `ghost` / `danger` / `quiet` |
| `controlClass()` / класс `.control` | свои `const field = "w-full px-3 py-2 ..."` | одна коробка ввода на весь продукт |
| `Field` | `<label>` рядом с полем | сам связывает через `htmlFor`, сам отдаёт полю класс |
| `Money` | любую сумму | принимает **центы** |
| `Readout` | крупный показатель-циферблат | знак валюты уходит на второй план |
| `Num` | **любое другое число** | счётчик, возраст, процент, номер телефона |
| `Stamp` | `toLocaleDateString(...)` | одна форма даты на весь продукт: `Aug 13, 2026` |
| `Chip` | свои обрамлённые «плашки» | утоплённая, без рамки |
| `Status` | пастельные пилюли | точка + моно-подпись |
| `Empty` | «ничего нет» | подпись + что делать дальше + кнопка |
| `Skeleton` | «Loading…» | линованные заглушки |
| `ErrorNote` | «Something went wrong» | называет отказ и следующий шаг |
| `TableWrap` + `Th` | голую `<table>` | своя горизонтальная прокрутка и `scope="col"` |
| `spineFor` / `textToneFor` / `railToneFor` | ручной подбор цвета статуса | спина / текст на светлом / текст на тёмной хроме |

Запрещено: сырой hex, `box-shadow`, радиус кроме `3px` и `999px` (только аватар и лампа),
эмодзи, декоративная анимация, «карточка с тенью», градиентный заголовок.

## 2. Что изменилось в фундаменте (было → стало)

| Было | Стало | Почему |
|---|---|---|
| `.row { padding: 13px 16px 13px 20px }` | `12px 16px 12px 20px` | 13 и 11 были единственным местом вне сетки |
| `:focus-visible { border-radius: 3px }` | правило убрано | круглый аватар в фокусе становился квадратным |
| `transition-all` на кнопке | перечень свойств | `all` анимировал и обводку фокуса: первые 140 мс кольцо было толщиной и цветом самой кнопки (у VOID — розовое 3px) |
| — | `.control` | девять экранов держали свою копию `w-full px-3 py-2 text-[13px]`, поля разъехались на 32/34/38/39/40px |
| — | `.chip` | плашки оборудования были в рамках и возвращали «сетку коробок» |
| — | `.actions` | на телефоне кнопки становятся по две в ряд, одиночная — во всю ширину |
| — | `.page-doc` (980px) и `.measure` (62ch) | заголовок записи начинался на 260/288/346/386/410/474/498 точке |
| — | `.t-micro … .t-page` | шкала кегля классами |
| — | `--fs-*`, `--sp-*` | кегль и отступы стали токенами |
| — | `--sky-rail` `--emerald-rail` `--rose-rail` `--slate-rail` | статус словом на тёмной хроме давал 2.6–3.2:1; новые двойники дают 7.7–8.7:1 |
| — | `railToneFor(status)` | выбирает эти двойники |
| `Empty` по центру | по левому краю, с подсказкой и действием | центрованная строка ломалась посреди фразы и читалась как плакат |
| `Field` отдавал `id` и обвязку | отдаёт ещё и `className` | поле больше не описывают руками |

Ничего не переименовано: старые токены, классы и имена примитивов работают как работали.

**Ловушка, стоившая часа.** Шкалу кегля НЕЛЬЗЯ заводить через `theme.fontSize` в
`tailwind.config`. `cn()` прогоняет классы через `tailwind-merge`, а тот читает
`text-<слово>` как цвет: в строке `text-body … text-plate` он видел два цвета, оставлял
последний и выбрасывал размер. Все кнопки продукта молча ехали на 16px браузера и росли с
38 до 42px. `tsc` и `lint` при этом чистые. Поэтому шкала — `.t-*` в `globals.css`.

## 3. Шкала кегля

Десять ступеней, одиннадцатой нет.

| Класс | px | Где |
|---|---|---|
| `.t-micro` | 10 | моно-засечки, буквы месячной ленты, самая мелкая надпись |
| `.eyebrow` | 11 | бровка — язык подписей всего продукта |
| `.t-meta` | 12 | деталь под заголовком строки |
| `.t-body` | 13 | по умолчанию |
| `.t-lede` | 14 | подзаголовок страницы и проза, больше нигде |
| `.t-row` | 15 | заголовок строки — то, что ищут глазами |
| `.t-record` | 22 | заголовок записи, число дня, телефон |
| `.t-readout` | 30 | денежный и счётный циферблат |
| `.t-page` | 34 → 44 c `md` | заголовок страницы (даёт `PageHead`) |

Что чем заменить: `8, 9 → .t-micro` · `16, 17, 18 → .t-row` · `19, 20 → .t-record` ·
`24, 26, 28 → .t-readout`; для заголовка вместо числа — `.t-record`.

`text-[19px]` и подобное — запрещено. Именно так двадцать размеров попали в систему из
десяти: каждый был частным решением, которого соседний экран не видит.

## 4. Отступы и ширина

Сетка: **4 / 8 / 12 / 16 / 24 / 40** (`--sp-1 … --sp-10`, в Tailwind `1 / 2 / 3 / 4 / 6 / 10`).
Половинные шаги (`1.5`, `2.5`) — только чтобы посадить текст на базовую линию соседа.
`pt-[19px]`, `pl-[14px]`, `py-[3px]` — вычистить.

Ритм:

- внутри строки — 12 по вертикали, 16 по горизонтали (даёт `.row`);
- между строкой и её деталью — 4;
- между блоками внутри секции — 16;
- между секциями — 40 (`mt-10`), секция открывается линейкой (`.lane` + `pt-4`);
- рамка — последнее средство: `воздух → смена поверхности → линейка → рамка`.

Ширина:

- экран-список идёт во всю деку;
- **запись и форма — `.page-doc` (980px)**, у всех одинаково;
- проза — `.measure` (62ch);
- поле ввода по ширине содержимого: пароль и сумма не должны быть на 630px.

## 5. Три состояния

Каждое состояние экрана оформляется одинаково во всём продукте.

**Пусто — это состояние.** Первая строка называет факт, вторая говорит, что делать,
кнопка это делает.

```tsx
<Empty
  hint="Accept an estimate and the invoice comes off it with the same lines."
  action={<Button variant="ghost" onClick={openEstimates}>See estimates</Button>}
>
  No invoices on this job
</Empty>
```

**Грузится.** `<Skeleton lines={4} />`. Голое «Loading…» на пустой деке читается как сбой.
Шапку записи (номер наряда и заголовок) рисовать сразу, скелетон — только под телом:
сейчас карточка работы секунду стоит пятью серыми полосами, и человек не знает, что открыл.

**Отказ.** `<ErrorNote>` называет, что не вышло, и что делать:

```tsx
<ErrorNote retry={<Button variant="ghost" onClick={retry}>Try again</Button>}>
  That invoice could not be sent — there is no email address on Ken Whitfield.
</ErrorNote>
```

Запрещено: «Something went wrong», «Error: undefined», «Failed to fetch», пустой экран
вместо отказа.

## 6. Таблица и длинный список на 390px

Таблица в продукте законна ровно в двух местах — печатный счёт и админский реестр. Везде
ещё — линованные строки.

- таблицу оборачивать в `<TableWrap>`, заголовки — `<Th>` (даёт `scope="col"`);
- в `.row` на телефоне: спина, заголовок, одна строка детали, число справа. Всё остальное
  прячется. Номер и точечный поводок (`.dotlead`) ниже `sm` уступают место имени;
- имя клиента держать целиком; обрезать хвост строки, сохраняя смысл;
- горизонтальной прокрутки документа быть не должно: проверяется в чеклисте;
- если список на телефоне длиннее экрана — сначала то, что горит сегодня.

## 7. Кнопки под палец

- **два роста на столе**: 38px (`primary` / `ghost` / `danger`) и 26px (`quiet` —
  действие внутри строки). Больше ростов нет;
- **44px на телефоне** — даёт сам примитив, не трогать;
- в одном кластере `.actions` ранги не смешивать: `quiet` живёт внутри строки, не рядом с
  `primary`;
- главное действие экрана на телефоне — во всю ширину (это делает `.actions`
  автоматически, когда кнопка одна);
- ссылка-бровка и `tel:` уже получают 44px площадь псевдоэлементом — не ломать это ростом
  коробки;
- заблокированное состояние — `disabled` у кнопки, `inertLook` у ссылки или `span`.
  `opacity-40` ставит подпись на 1.9:1 — на солнце кнопки просто нет.

## 8. Язык интерфейса

Английский, для подрядчика из Оттавы: `job`, `crew`, `estimate`, `invoice`, `truck`, `stop`.

- одно понятие — одно слово. Сейчас `Crew` в рельсе, `Tasks` в заголовке и `CREW BOARD` в
  бровке — на одном экране. Внутри волны сверять словарь с соседями;
- конструкция «not X, but Y» и предложения, начинающиеся с противопоставления, запрещены.
  На `/login` сейчас: «…who run on tickets, not on enterprise pipelines» — переписать;
- дата — `Stamp`, один вид на весь продукт. `2026-07-27` рядом с `Jul 27, 2026` — это
  восемь мест с `toLocaleDateString("en-CA")`;
- деньги — только `Money cents={…}` или `formatCents`;
- эмодзи в интерфейсе нет.

## 9. Чеклист перед сдачей экрана

Пройти по своему экрану в двух ширинах и в своей роли.

1. Сырых hex нет; цвет только токеном.
2. Радиус только `3px` (и `999px` на аватаре/лампе). Теней ноль.
3. Кегль только из шкалы §3. `text-[Npx]` не осталось.
4. Отступы по сетке §4. Заголовок начинается там же, где у соседних экранов.
5. Все числа моно и tabular: `Money`, `Readout`, `Num`, `Stamp` или `.mono`.
6. Все даты через `Stamp`.
7. Каждое поле в `Field` (подпись связана `htmlFor`, ошибка звучит).
8. Кнопки только через `Button` / `buttonClass`. Ростов два: 38 и 26 на столе, 44 на телефоне.
9. Пусто / грузится / отказ — по §5, каждое говорит, что делать дальше.
10. На 390px документ не едет вбок, ни одна цель нажатия не меньше 44px.
11. Фокус с клавиатуры виден на каждом шаге Tab; на тёмной хроме — `focus-rail`.
12. Движение: одна кривая `--ease`, длительности `--t-fast` / `--t`, декоративного нет,
    `prefers-reduced-motion` уважается.
13. Словарь совпадает с соседними экранами.
14. Скриншоты «до» и «после» в обеих ширинах лежат в `var/polish/<трек>/`.
15. `npx tsc --noEmit`, `npm run lint`, `npm run test` — зелёные.

## 10. Находки по группам экранов

Замер 13.08.2026, обе ширины, роль ADMIN (`var/polish/base/audit-after.json`).
`кегль` — сколько элементов вне шкалы; `числа` — сколько чисел набрано пропорциональным
шрифтом; `поля` — сколько элементов управления без имени.

| Группа | кегль | числа | поля | росты кнопок на столе | левый край h1 | всего |
|---|---|---|---|---|---|---|
| Диспетчерская + Today | 17 | 42 | 0 | 11/31/48 | 260 / 498 | **59** |
| Лиды | 24 | 4 | 6 | 11/23/25/31/37/38/54 | 260 / 474 | **34** |
| Клиенты | 24 | 18 | 2 | 25/26/31/37 | 260 / 346 | **44** |
| Работы + смета | 7 | 38 | 4 | 30/31/37 | 260 / 410 / 386 | **49** |
| Счета | 8 | 11 | 8 | 31/37 | 260 / 288 | **27** |
| Деньги (Finance + Reports) | 4 | 4 | 4 | 27/31/37 | 260 | **12** |
| Контракты + Crew | 72 | 24 | 0 | 14/29/31/37 | 260 | **96** |

| **Итого** | **178** | **143** | **72** | 15 разных ростов | 7 разных краёв | **393** |

### 10.1 Диспетчерская и Today

- 19px×16 и 28px×1 вне шкалы — это лента недели и карточки поля;
- 42 числа не моно — самый большой очаг в продукте (счётчики дня, «3 stops to go»);
- пустая неделя рисуется большим пустым прямоугольником: под «THE WEEK» голая черта и
  ничего. Нужен `Empty` с подсказкой (`DayRail.tsx:292`, см. A11Y 4.12);
- `Today` заголовок начинается на 498 точке против 260 у соседей;
- на карточке поля `CALL` без телефона и `Done` гашены `opacity-40/50` (1.9:1) — заменить
  на `inertLook` (A11Y 4.5);
- сортировка: перенесённая работа стоит выше сегодняшней стоянки (FIELD-TEST Б3) — это
  функциональная находка, чинит не полишер.

### 10.2 Лиды

- 26px×14 и 16px×8 вне шкалы: `LeadClock` печатает секундомер 26px, счётчики строк 16px;
- заголовок карточки лида 26px против 44px у списков — на шкале это `.t-record` 22 или
  `.t-page`;
- семь ростов кнопок: `const act / actQuiet / actPrimary` в `leads/page.tsx:66-70` —
  заменить на `buttonClass("quiet" | "ghost" | "primary")`;
- 6 элементов управления без имени; 7 подписей без `htmlFor` в списке, 7 в карточке;
- строка засечек ожидания (`LeadWait`) на 390px читается как мусор из палок —
  пересмотреть подачу, не трогая арифметику;
- модалка конверсии не знает про клавиатуру (A11Y 4.3): `role="dialog"`, ловушка фокуса,
  Esc, возврат фокуса.

### 10.3 Клиенты

- 18px×12 и 20px×6 вне шкалы; 9px×2 — буквы алфавитного рельса;
- буквы без клиентов идут `opacity-35` (1.6:1) — последний провал контраста в продукте
  (A11Y 4.6);
- живая буква рельса шириной 11px — на телефоне поднять до `px-2`;
- телефон в строке лежит под накладной ссылкой строки и не получает нажатие;
- 18 чисел не моно; чипы оборудования — перевести на `.chip`.

### 10.4 Работы и смета

- 38 чисел не моно — второй по величине очаг;
- дата в шапке работы печатается `2026-07-27`, у соседей `Jul 27, 2026` → `Stamp`;
- четыре `<button>` изображают вкладки без `role="tablist"` (A11Y 4.9);
- смета: заголовок начинается на 386 точке, работа — на 410, списки — на 260 → `.page-doc`;
- пустая смета говорит «NO ESTIMATES ON THIS JOB YET» и не говорит, что делать;
- 12 подписей без `htmlFor` в смете, 8 в карточке работы;
- пока карточка грузится, у неё нет ни номера, ни заголовка — только пять серых полос.

### 10.5 Счета

- 19px×4, 20px×2, 26px×2 вне шкалы;
- полоса старения — сплошная заливка в три цвета во всю ширину: янтарь и семантика здесь
  работают краской, тогда как по закону это источник света. Приглушить, оставив смысл;
- 8 элементов управления без имени; поиск и фильтр висят на шапке первой полосы, а
  относятся ко всему экрану;
- `<th>` без `scope` в печатном счёте, таблица без явной обёртки → `TableWrap` + `Th`;
- заголовок записи начинается на 288 точке.

### 10.6 Деньги (Finance и Reports)

- «NO MONEY IN THIS PERIOD» — состояние без следующего шага;
- ссылки выгрузки CSV 63×17 на телефоне;
- 10 подписей без `htmlFor` в Finance;
- полка каналов в Reports шире контейнера, седьмая колонка обрезана без подсказки;
- `COLLECTED $0.00` печатается изумрудом — тон несёт категорию вместо величины
  (FIELD-TEST А3). Ноль — нейтральным.

### 10.7 Контракты и Crew

- **72 элемента на 8px** — буквы месячной ленты `J F M A M J J A S O N D`. Это весь
  бюджет расхождений группы: поднять до `.t-micro` (10px);
- ячейка месяца различает три состояния только заливкой, без подписи и легенды (A11Y 4.7);
- точка `·` в пустой ячейке — 2.02:1 (A11Y 4.8);
- выбор плана в форме контракта — псевдо-радиокнопки без `role`;
- чипы `HEAT PUMP · MITSUBISHI` обрамлены рамками → `.chip`;
- **Crew: рельс говорит «Crew», заголовок «Tasks», бровка «CREW BOARD»** — три слова на
  одно понятие. Выбрать одно;
- `<select>` смены полосы без имени, восемь штук на экране (A11Y 4.10);
- 24 числа не моно (даты на карточках задач).

### 10.8 Настройки и аккаунт

- **48 элементов управления без имени** — половина всех в продукте;
- 17px×14 и 20px×8 вне шкалы;
- поля формы во всю ширину плиты: пароль растянут на 630px;
- форма аккаунта и форма реквизитов держат свои коробки ввода → `.control`;
- вход: ошибка появляется обычным `<p>`, читалка молчит; полям не хватает `autoComplete`

## 11. Сервер и скриншоты

```bash

```

Вход: `admin@handyman.ca` / `admin123` (ADMIN), `worker1@handyman.ca` / `worker123`

Три вещи, которые стоили этой волне времени:

1. **Два dev-сервера на одном `.next` бьют друг другу чанки.** Симптом — `TypeError:
   Cannot read properties of undefined (reading 'call')` на `/api/auth/session` и 500 на
   входе. Разные порты не спасают: каталог сборки один на репозиторий. Значит, семь
   агентов не могут держать семь серверов одновременно — снимать по очереди, а перед
   своим прогоном проверять `ps -ef | grep "next dev"`. Если чанки уже побиты —
   `rm -rf .next` и перезапуск (на момент сдачи волны сервера не осталось, `.next` чист).
2. **`npm run test` нельзя запускать при живом dev-сервере**: e2e-наборы работают с той же
   `dev.db`. Вместе они дают до пяти красных файлов, по отдельности — 354 из 354 зелёных.
   Сначала гасим сервер, потом тесты.
3. `favicon.ico` отдаёт 500 в dev — известный артефакт, игнорировать.
